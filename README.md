# 我们的家

按带尺寸户型图制作的三室两厅一卫浏览器 3D 住宅，支持电脑第一人称行走、手机双手触控、墙体与家具碰撞、鸟瞰、小地图及日期和时间控制的日照模拟。

## 本地运行

需要 Node.js 22.12 或更高版本。项目使用 Three.js 0.180.0 和 Vite 7.1.9；依赖安装使用 `.npmrc` 中的华为 npm 镜像。

```sh
npm ci
npm run dev
```

浏览器打开终端显示的网址，默认 `http://localhost:5173/`。同一局域网内的手机可使用电脑的局域网 IP 和端口访问。通过网站服务访问，不直接双击 HTML 文件。

## 操作

- 电脑：点击场景或“走进我们的家”，锁定后隐藏鼠标光标；WASD 行走，鼠标看四周，Shift 加速，Esc 释放并恢复光标。部分内置浏览器拒绝鼠标锁定时会显示提示，请在独立的 Edge 或 Chrome 打开；鸟瞰和日照仍可使用。
- 手机：点击“走进我们的家”，左侧摇杆行走，右侧拖动看四周，可双手同时操作；按住“加速”按钮加速。
- 按 M 或点击“鸟瞰全屋”切换鸟瞰，再次切换恢复原站位。鸟瞰用鼠标旋转和滚轮缩放；手机单指旋转、双指缩放。
- 按 1–9 依次前往客厅、餐厅、主卧、南次卧、北次卧、厨房、卫生间、南阳台、玄关；房间菜单还可前往过道。
- 底部选择日期，拖动 05:00–20:00 时间滑块；按空格或播放按钮播放、暂停约 30 秒的日照延时。
- 点击日照面板右侧的“−”收起为时间小条，点击“+”展开。左上角显示图纸建面和套内建面。
- “设置”中可修改经纬度、UTC 偏移和户型图上方方位角；0° 北、90° 东、180° 南、270° 西。操作表单会暂停行走，点击场景继续。

## 构建与部署

```sh
npm run build
npm run preview
```

构建生成 `dist/`，预览默认 `http://localhost:4173/`。所有运行依赖已打包到静态文件中，网站访问时无需第三方 CDN。

现有服务器：把 `dist/` **里面的** `index.html` 和 `assets/` 上传到网站根目录。部署包 `virtual-home-site.zip` 的根层级已是这些文件，可直接解压上传。

Cloudflare Pages：直接上传解压后的部署包内容；或使用源码构建，项目根目录设置为 `virtual-home`（如果仓库根目录就是本项目则留空），构建命令 `npm run build`，输出目录 `dist`，Node 版本设置为 22。部署到 HTTPS 网址后，电脑和手机访问同一网址。

根目录 `vite.config.js` 设置资源基路径及本地端口，当前 `base: './'` 可用于静态子目录。房屋和日照参数集中在 `floor-plan.json`；修改后重新构建。

## 户型数据与日照范围

`floor-plan.json` 包含房间轮廓、墙体、洞口、家具、站位和尺寸估算。单位米，平面原点在左下角，x 向右、y 向上；映射到 Three.js 为 `(x, height, -y)`。

面积依图纸：建筑面积 106.53㎡、套内建筑面积 82.33㎡。这些面积不作为室内净地面面积，也不用于缩放户型。图纸红框内已是实际镜像方向，模型上北下南，阳台朝南。

未标注净高暂按 2.8m、墙厚 0.2m，门窗及阳台部分尺寸为估算，详见 JSON 的 `assumptions`。家具是基础几何体的示意布置。

太阳位置按 NOAA 公式结合日期、时间、经纬度与时区计算。只计算房屋自身的晴空日照；住宅楼层、周边楼高和楼间距未知，未模拟周边建筑遮挡。

页面和交付文件使用通用名称，未包含小区名、楼栋号、具体地址或原始参考图片/PDF。日照配置保留城市级近似经纬度，可在设置中修改。

## 验证记录

已在本机 Edge 浏览器确认场景加载、鼠标锁定和释放、行走、碰撞、房间通行与瞬移、鸟瞰切换、日期/时间和日夜灯光。已用触屏浏览器模拟检查手机横竖屏布局及双触点摇杆/视角操作。

2026-10-14 复查修正了锁定拒绝触发整页错误、光标状态、日照面板占用视野、手机旋转后画布扩大与鸟瞰取景、窄屏控件遮挡。原生鼠标锁定的拒绝路径用浏览器内注入失败验证，未修改浏览器本身。

性能优化：太阳阴影在时间或相关显示状态变化时更新；白天强度为零的室内灯不参与着色，夜间重新开启。Intel HD Graphics 630、Edge、1440×900 的日间场景对比测量中，静止画面绘制次数从每帧 661 次降到 179 次；移除零强度室内灯后 GPU 平均耗时从约 17.6ms 降到 7.1ms，最后一轮约 60fps。这是本机测试结果，实际帧率随设备和视角变化。

未验证真实手机和 iPhone Safari，也未测量这些设备的帧率；需要支持 WebGL2 的现代浏览器。未验证实际服务器或 Cloudflare 部署，交付为可部署静态产物。
