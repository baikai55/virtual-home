# 我们的家

按带尺寸户型图制作的三室两厅一卫浏览器 3D 住宅，支持电脑第一人称行走、手机双手触控、墙体与家具碰撞、鸟瞰、小地图、尺寸平面、可展开的户型尺寸表及日期和时间控制的日照模拟。页面可添加到手机主屏幕，并在首次访问后离线打开。

## 本地运行

需要 Node.js 22.12 或更高版本。项目使用 Three.js 0.180.0 和 Vite 7.1.9；依赖安装使用 `.npmrc` 中的华为 npm 镜像。

```sh
npm ci
npm run dev
```

浏览器打开终端显示的网址，默认 `http://localhost:5173/`。同一局域网内的手机可使用电脑的局域网 IP 和端口访问。通过网站服务访问，不直接双击 HTML 文件。

## 操作

- 电脑：点击场景或“走进我们的家”，锁定后隐藏鼠标光标；WASD 行走，鼠标看四周，Shift 加速，Esc 释放并恢复光标。部分内置浏览器拒绝鼠标锁定时会显示提示，请在独立的 Edge 或 Chrome 打开；鸟瞰和日照仍可使用。
- 手机：点击“走进我们的家”，左侧摇杆行走，右侧拖动看四周，可双手同时操作；按住“加速”按钮加速。
- 按 M 或点击“鸟瞰全屋”切换鸟瞰，再次切换恢复原站位。鸟瞰用鼠标旋转和滚轮缩放；手机单指旋转、双指缩放。
- 按 1–9 依次前往客厅、餐厅、主卧、南次卧、北次卧、厨房、卫生间、南阳台、玄关；房间菜单还可前往过道，并显示图纸轴线尺寸。
- 电脑点击工具条“尺寸平面”进入尺寸平面：房间标签显示模型宽×深，较大的房间同时显示约面积；大件家具同时显示名称和模型宽×深（不含高度），家具标签在房间标签之后避让。再次点击或“回到房间”退出。
- 小地图只显示短房间名和约面积，点击任意房间可直接前往。右上角“⤢”放大户型图并展开“房间尺寸表”，列出模型尺寸、约面积和图纸轴线尺寸/备注；下方的“家具尺寸表”列出全部家具的平面尺寸。点击背景、× 或按 Esc 关闭。
- 手机点工具条“标注”进入同一尺寸平面，双指缩放查看标注；平面左上角“家具/房间”切换图层，默认先看家具。右上角小地图的“⤢”打开房间/家具尺寸表。
- 底部选择日期，拖动 05:00–20:00 时间滑块；按空格或播放按钮播放、暂停约 30 秒的日照延时。
- 点击日照面板右侧的“−”收起为时间小条，点击“+”展开。左上角显示图纸建面和套内面积。
- “设置”中可修改经纬度、UTC 偏移和户型图上方方位角；0° 北、90° 东、180° 南、270° 西。设置会保存在本机浏览器，“恢复默认”清除保存值。操作表单会暂停行走，点击场景继续。
- 手机浏览器菜单中的“添加到主屏幕”可全屏打开；首次加载后支持离线打开。手机小地图收起后会停到右上角，不再单独占一行。

## 构建与部署

```sh
npm run build
npm run preview
```

构建生成 `dist/`，预览默认 `http://localhost:4173/`。所有运行依赖已打包到静态文件中，网站访问时无需第三方 CDN。`dist/` 还包含 `manifest.webmanifest`、`sw.js`、`_headers`、PWA 图标和分享预览图。

现有服务器：把 `dist/` **里面的所有文件**上传到网站根目录。`_headers` 用于给带哈希的 `assets/` 设置一年 immutable 缓存；服务器不支持该文件时不影响页面，只是少一层浏览器缓存优化。

Cloudflare Pages：直接上传解压后的部署包内容；或使用源码构建，项目根目录设置为 `virtual-home`（如果仓库根目录就是本项目则留空），构建命令 `npm run build`，输出目录 `dist`，Node 版本设置为 22。Cloudflare Pages 会自动应用 `_headers`；部署到 HTTPS 网址后，电脑和手机访问同一网址，首次访问后由 Service Worker 提供离线缓存。

根目录 `vite.config.js` 设置资源基路径及本地端口，当前 `base: './'` 可用于静态子目录。房屋和日照参数集中在 `floor-plan.json`；修改后重新构建。分享预览图 `og-image.jpg` 及 `index.html` 中的 `og:url`/`og:image` 按 `https://house.yueming.uk/` 配置，换域名时需要同步修改。

## 户型数据与日照范围

`floor-plan.json` 包含房间轮廓、墙体、洞口、家具、站位和尺寸估算。单位米，平面原点在左下角，x 向右、y 向上；映射到 Three.js 为 `(x, height, -y)`。房间的 `dimensionLabel` 保存图纸轴线尺寸/备注，用于房间菜单和尺寸表；`mapName` 是小地图短名；`overview` 与 `planView` 分别控制鸟瞰和尺寸平面的取景。家具条目中的 `w`/`d` 是模型平面宽/深，`dimension: true` 表示在尺寸平面显示标签；家具尺寸表列出全部家具，圆桌按直径显示。模型尺寸由房间轮廓外接框计算，L 形房间会注明；面积由轮廓多边形按墙中线计算，不是图纸建面或套内净地面面积，详见尺寸表底部说明。

面积依图纸：建筑面积 106.53㎡、套内建筑面积 82.33㎡。这些面积不作为室内净地面面积，也不用于缩放户型。图纸红框内已是实际镜像方向，模型上北下南，阳台朝南。

未标注净高暂按 2.8m、墙厚 0.2m，门窗及阳台部分尺寸为估算，详见 JSON 的 `assumptions`。家具是基础几何体的示意布置，家具尺寸取模型平面轮廓，不含高度。

太阳位置按 NOAA 公式结合日期、时间、经纬度与时区计算。只计算房屋自身的晴空日照；住宅楼层、周边楼高和楼间距未知，未模拟周边建筑遮挡。

页面和交付文件使用通用名称，未包含小区名、楼栋号、具体地址或原始参考图片/PDF。日照配置保留城市级近似经纬度，可在设置中修改。
